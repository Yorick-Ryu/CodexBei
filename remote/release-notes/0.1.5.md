CodexBei 0.1.5

- 修复重复点击一键配置时意外切回 API 的问题：首次接入默认 API，后续保留当前通道，用户主动选择优先；网页配置链接导入时启用 API。
- 新增 API 账户余额、密钥额度、生效套餐和充值入口，仅在配置完成页显示。
- 改进余额查询：失败后自动重试，网络恢复或重新进入后可再次查询，成功结果继续缓存。
- 改善 Windows 安装体验：微软商店不可用时转到安装程序下载，同时提供直接下载入口。
- 发布文件改为按版本独立存储，保留历史下载地址，支持独立发布和回滚。

支持 macOS Apple 芯片 / Intel、Windows x64 / ARM64。macOS 安装包经过签名与公证，四个平台的自动更新包均附更新签名。
