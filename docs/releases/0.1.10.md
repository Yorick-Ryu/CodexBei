# CodexBei 0.1.10

- 新增 Claude 桌面版独立配置，支持 BeiAPI 等兼容 Anthropic Messages 的第三方 API。
- 填写密钥即可一键配置；API 地址、模型、模型发现和 1M 上下文选项收进“更多设置”。
- 自动获取原生 Claude 模型列表，模型发现和 1M 上下文默认开启。
- API 地址移到模型上方，统一各页面文案及底部提示条，成功提示 3 秒后自动消失。
- 更新检查保持静默，不再阻塞配置操作。
- 移除额度区域的充值按钮。

支持 macOS Apple Silicon / Intel 和 Windows x64 / ARM64。Windows 完成原生构建与安装包验证，Claude 实际对话仍待 Windows 实机验收。1M 上下文的实际可用性取决于模型及网关支持。
