# CodexBei 0.1.12

- Claude 桌面版新增安装检测和引导，未安装时提供下载与重新检测入口；安装完成后自动开放配置并停止轮询。
- 下载入口接入社区原包镜像，macOS 使用通用 DMG，Windows 按架构选择 x64 或 ARM64 MSIX。
- Claude 桌面版的字段间距和提示区域与 ChatGPT 页面保持一致，显示模型获取提示时不再挤动下方选项。
- 统一安装引导文案，精简模型获取失败和空列表提示。

支持 macOS Apple Silicon / Intel 和 Windows x64 / ARM64。镜像由第三方维护；Windows 安装包执行原生构建、测试及静默安装验证，未进行 Claude 实际对话验收。
