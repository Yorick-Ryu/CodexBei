# CodexBei 0.2.0

- ChatGPT、Claude Code 和 Claude 桌面版的 API 地址支持下拉选择和输入筛选，也可填写自定义地址。两个 BeiAPI 主站排在最前，后面是 NovAPI 和 DianAPI。
- ChatGPT 配置默认优先使用 WebSocket。读取到非预设的第三方 API 地址时，配置界面默认推荐 BeiAPI 地址。
- Claude 桌面版切换 API 地址时会保留已输入的密钥，可以查看可读取的已保存密钥。模型按 Fable、Opus、Sonnet、Haiku、Mythos 排列，同系列新版在前。
- Windows 版检测到 Claude 桌面版运行组件缺失时会提供修复入口。ChatGPT 安装入口打不开时，可从提示中复制下载链接。

支持 macOS Apple Silicon / Intel 和 Windows x64 / ARM64。
