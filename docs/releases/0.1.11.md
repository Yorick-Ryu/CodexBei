# CodexBei 0.1.11

- Claude 桌面版新增“允许访问所有网站”开关，可在“更多设置”中配置网页抓取、内置浏览器和命令的出站联网。
- 首次配置默认关闭联网，已有配置自动读取当前状态；保存后重新打开 Claude 生效。
- 修复已有默认模型时重新配置可能只保留一个模型的问题，重新填写密钥后会获取完整的原生 Claude 模型列表。

支持 macOS Apple Silicon / Intel 和 Windows x64 / ARM64。macOS 已实测 Claude 桌面版网页抓取及命令访问外网；网站自身、网络环境和 Claude 站点安全检查仍可能限制访问。Windows 安装包执行原生构建、测试及静默安装验证，未进行 Claude 实际对话验收。
